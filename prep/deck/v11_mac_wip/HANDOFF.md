Этот файл для новой сессии Claude, например в Claude Desktop, где есть встроенный браузер. Начните с него.

## Задача

Пользователь открыл редактируемый PPTX в PowerPoint и увидел проблемы, какие именно — ещё не описаны. Нужно:
1. открыть файл в PowerPoint (PowerPoint для веба во встроенном браузере Claude Desktop);
2. пролистать все слайды в режиме слайд-шоу, проверить вёрстку и щелчки;
3. исправить генератор (`pptx_tools/`), пересобрать, проверить снова;
4. положить исправленные файлы в `prep/deck/`, закоммитить и запушить.

## Как открыть файл в PowerPoint для веба

Встроенный браузер работает на компьютере пользователя, поэтому сетевые ограничения облачной песочницы на него не действуют.

**Без входа в аккаунт** — просмотрщик Office по публичной ссылке на файл из GitHub:

```
https://view.officeapps.live.com/op/view.aspx?src=https://raw.githubusercontent.com/Neoron95/conference-hardfest-algorithms/refs/heads/claude/conference-talk-prep-fkipal/prep/deck/hardfest2026_deck_v21_mac_editable_prod.pptx
```

Для другого файла замените имя в конце ссылки. Просмотрщик может отказаться от больших файлов (наши весят 17–28 МБ). Тогда идите вторым путём.

**С входом** — office.com:
1. Откройте https://www.office.com во встроенном браузере и попросите пользователя войти в аккаунт Microsoft.
2. Файл в OneDrive пользователь загружает сам: перетаскивает или выбирает с диска. Встроенный браузер не открывает файлы из папки сессии.
3. Откройте файл в PowerPoint для веба, включите «Слайд-шоу» с начала и листайте щелчками, сверяясь с колодой.

Что сверять: положение и переносы строк, шрифт (Montserrat, а не подставленный), плашки и рамки, порядок появления по щелчкам (разметка `[щелчок]` в `slides_text.md`), запуск видео на слайдах 1, 19, 20, 25 и 30.

## Что уже проверено и что нет

- ✅ Все три файла проходят валидатор PPTX.
- ✅ Вариант clicks: сумма слоёв попиксельно совпадает с рендером колоды.
- ✅ Вариант editable: собственный предпросмотр теми же шрифтами по модели PowerPoint совпадает с колодой на всех 50 слайдах; ни одна строка не шире своего блока.
- ❌ В настоящем PowerPoint ничего не проверено. Главные подозреваемые: вертикальная посадка строк (коэффициент 0,8 в `convertB.py`), встроенные шрифты (формат EOT `.fntdata` в `post.py`), анимации (`build_timing()` в `post.py`).
- ⚠️ В Keynote editable разваливает щелчки одного шага на отдельные, а видео показывает раньше его щелчка. Пользователь сказал, что версия под Keynote пока не нужна.

## Правила пользователя

- Общаться по-русски. Ответы короткие и по делу.
- На слайдах меньше текста, речь короче.
- Коммитить и пушить только в ветку `claude/conference-talk-prep-fkipal`, PR не создавать без просьбы.
- Колоду Xeon (https://claude.ai/artifact/GWhTe2x15PgEoctLSvtkz8) не трогать.
- При замене слайда в колоде: новый id `-vN`, старый скрыть.
- Мемы оставлять. На слайдах с доской подозреваемых нет логотипа.
- Перед публикацией в артефакт перечитывать живые файлы: пользователь правит колоду сам.
- Идентификаторы моделей в коммиты и файлы не писать.

## С чего начать

1. Спросить у пользователя, какие проблемы он увидел в PowerPoint: какие слайды, что не так. Скриншоты ускорят дело.
2. Открыть `prep/deck/hardfest2026_deck_v21_mac_editable_prod.pptx` в PowerPoint для веба (см. выше) и пройти все слайды.
3. Править генератор в `pptx_tools/`, пересобирать `./build.sh`, проверять снова.
