# Сборка PPTX из колоды

Скрипты собирают PowerPoint-файлы из HTML-слайдов колоды (`../project` — точная копия колоды-артефакта).

| Файл в `out/` | Что внутри |
|---|---|
| `hardfest2026_deck_mac_clicks.pptx` | Слайды картинками, разрезанными по щелчкам. Выглядит один в один с колодой, текст не редактируется |
| `hardfest2026_deck_mac_editable.pptx` | Текст и плашки — редактируемые объекты PowerPoint; схемы, графики, мемы — картинками |
| `hardfest2026_deck_mac_editable_prod.pptx` | То же, что editable, но только 39 слайдов основной части и без заметок спикера |

Во всех трёх: щелчки как в колоде, видео встроены и стартуют со своим щелчком, речь и подсказки в заметках (кроме prod), шрифты Montserrat и JetBrains Mono встроены в файл.

## Запуск

**В облачной сессии Claude Code** (Playwright и Chromium там уже есть):

```bash
cd prep/deck/v11_mac_wip/pptx_tools
npm install
pip3 install -r requirements.txt
./build.sh            # около 1,5 минуты, результат в out/
```

**На своём компьютере** (macOS или Linux; нужны Node 18+ и Python 3.10+):

```bash
cd prep/deck/v11_mac_wip/pptx_tools
npm install
npx playwright install chromium
pip3 install -r requirements.txt
./build.sh
```

Готовые файлы для показа лежат в `prep/deck/hardfest2026_deck_v21_mac_*.pptx`. После пересборки скопируйте нужные из `out/` туда же.

## Если колода поменялась

1. Обновите `../project`: `deck.json` и файлы `slides/<id>.html` из артефакта колоды.
2. Если на слайде появилась новая картинка или видео (`/_blob/<id>`), положите файл в `assets/<id>.<расширение>`. `make_pages.py` сам скажет, какого ассета не хватает.
3. Запустите `./build.sh`. Скрытые слайды (`<section hidden>`) в PPTX не попадают.

## Как устроено

| Шаг | Скрипт | Что делает |
|---|---|---|
| 1 | `make_pages.py` | Слайды → отдельные HTML-страницы с локальными ассетами и шрифтами (`build/pages`), заметки, длительность видео |
| 2 | `layersA.js`, `cropA.py` | Вариант clicks: рендер в Chromium по слоям — фон и по картинке на каждый щелчок. Проверка: сумма слоёв попиксельно совпадает с полным рендером |
| 3 | `buildA.js` | Вариант clicks: сборка PPTX (pptxgenjs) и план анимаций |
| 4 | `extractB.js`, `convertB.py` | Вариант editable: из браузера берутся строки текста с их стилями, плашки, рамки, картинки и SVG (в 2×) → `build/B/spec.json` |
| 5 | `buildB.js` | Вариант editable: сборка PPTX. `MAXN=39 NONOTES=1 OUT=build/P` — версия prod |
| 6 | `post.py` | Дописывает в PPTX анимации (щелчки, автозапуск видео) и встраивает шрифты |
| 7 | `previewB.py` | Проверка editable: рисует каждый слайд из `spec.json` теми же шрифтами по модели PowerPoint и сравнивает с колодой (`build/B/compare-*.png`) |

**Щелчки.** Атрибут `data-build-in="fade N"` у элемента колоды — номер шага N. Все элементы шага появляются вместе, эффектом «Выцветание». `auto` значит: появляется сам после предыдущего шага, без щелчка. Видео появляется вместе со своим шагом, сразу запускается, крутится по кругу и без звука.

**Модель текста в editable** (`convertB.py`):
- 1 px колоды = 1/144 дюйма = 0,5 pt; слайд 13,333 × 7,5 дюйма (16:9);
- строки переносятся ровно там, где в браузере: разрывы проставлены явно, автоперенос выключен;
- интервал строк «точно» = line-height колоды; верх блока = базовая линия первой строки − 0,8 × интервал;
- начертания Montserrat — отдельные гарнитуры: «Montserrat», «Montserrat Medium», «Montserrat SemiBold», «Montserrat ExtraBold», а 700 — это «Montserrat» жирным;
- знаки, которых нет в Montserrat (сейчас только ✓ и ✗), вставляются маленькими картинками.

**Шрифты** встраиваются в формате, который понимает PowerPoint: EOT в `ppt/fonts/*.fntdata`, файлы в `fonts/embed`. Keynote встроенные шрифты не использует: для него нужен установленный Montserrat.

## Где править, если в PowerPoint что-то не так

| Симптом | Где |
|---|---|
| Все строки чуть выше или ниже, чем в колоде | `convertB.py`: коэффициент `0.8` в строке `y=out_lines[0]['base']-0.8*L` |
| Не тот вес или шрифт у текста | `convertB.py`: функция `face()` |
| Текст переносится не там | `convertB.py`: ширина блока, `wrap:false` в `buildB.js` |
| Анимации, порядок щелчков, видео | `post.py`: функция `build_timing()` |
| Плашки и рамки | `convertB.py`: ветка `box`; `buildB.js`: `rect` / `round` / `line` |

## Известные ограничения

- **Keynote:** в editable щелчки одного шага появляются по отдельности, а видео видно и играет до своего щелчка. Вариант clicks в Keynote надёжнее, но и там видео может появиться раньше.
- **LibreOffice** в облачной песочнице не запускается, поэтому визуально проверялось только своим предпросмотром (`previewB.py`), а не PowerPoint.
- **PowerPoint** напрямую не проверен. Пользователь сообщил, что в PowerPoint есть проблемы; какие именно — ещё предстоит посмотреть (см. `../HANDOFF.md`).
