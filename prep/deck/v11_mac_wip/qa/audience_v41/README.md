## Что сработало у всех

- Завязка: диф, «апрув почти не глядя», голосование (5–7) и «три устройства — три ответа» (11).
- «O-большое считает шаги, платим за цену шага» (14) — дословно запомнили все пятеро.
- Модель «работа + ожидание + выброшено» и табло в углу (15–24) — по нему держали нить.
- Узлы, окно, «malloc выталкивает следующий промах» (19–22) — сеньор и олимпиадник назвали лучшим местом доклада.
- Сортировка без ветвлений: команд больше, а быстрее в 2,6 раза (24).
- QoS utility → E-ядро, доказанное лестницей (31–32) — главное открытие для iOS-слушателей; сеньор забирает технику себе.
- Три вопроса для ревью «контракт / данные / исполнение» (38) — унесут все.
