Под рукой:
• iPhone 14 Pro, A16 Bionic. Версия iOS и мобильные сырые данные не сохранены в доступных материалах исходной серии; размеры кэшей iPhone не подставлять из модели. Время — медианы, числа перенесены из существующей колоды. Версия iOS, полный номер сборки DedupBench и его флаги не сохранены в доступных материалах исходной серии. Не заполнять эти поля выдуманными значениями и не обещать, что полный мобильный паспорт лежит в репозитории.
• Mac — M2 Pro, macOS 27, исходная подпись Xcode 27.0/Apple clang 21.0.0, libc++, -O3. Конфигурация числа P/E ядер не сохранена; не выбирать 6P/8P по модели. Сохранённый sysctl: P L1D 128 КиБ/L2 16 МиБ; E L1D 64 КиБ/L2 4 МиБ; hw.cachelinesize 128 Б.
• Исходная x86-серия — Xeon в VM, GCC 13. Независимый повтор bench/results/env.txt: GCC 13.3/libstdc++, Clang 18.1/libc++, базовый x86-64 -O3, taskset -c 2; PMU недоступен. Объявленный L3 VM не доказывает фактически доступный кэш.
• Hosted macOS-раннеры обсуждались как отдельный пример VM: конфигурация раннера меняется во времени, точный CPU/perflevel проверить у конкретного запуска. Один виртуальный perflevel не гарантирует постоянного физического P-ядра и не исключает влияние QoS через хост.
• Swift Task: priority не задаёт executor. Task наследует actor isolation; созданный из MainActor Task с синхронным C++ вызовом может остаться на MainActor. Ожидание через await task.value может повысить приоритет. Замер через Swift Task не выполнялся. Первоисточник: SE-0304, разделы Task priorities, Priority Escalation, Context inheritance: https://github.com/swiftlang/swift-evolution/blob/main/proposals/0304-structured-concurrency.md . Не рекомендовать Task.detached автоматически: сначала определить реальный executor.
• UserInitiated — приоритет, не состояние приложения. Utility и реальный background процесса различаются. BGAppRefreshTask не измерялся; соответствие лаборатории продукту не утверждать.
Источники: prep/research/apple.md §2, §6–7; bench/README.md; bench/results/env.txt; SE-0304.
