Один проход: берём число, если оно не равно соседу

Давайте для начала вспомним теорию. Начнём с первого способа: Сортировки. Возьмём шесть чисел.

[щелчок] Внутри std::sort — быстрая сортировка, точнее её доработанная версия, introsort. Берём опорное число, например три, и делим на две части: всё, что не больше трёх, — налево, всё, что больше, — направо.

[щелчок] Дальше то же самое внутри каждой части — пока куски не станут по одному. И смотрите: одинаковые встали рядом.

[щелчок] Остаётся один проход слева направо: берём число, если оно не равно соседу. Получили один, три, семь, девять. Вся работа — сравнения и перестановки в одном массиве, без лишней памяти.

Подсказки
• Части две. Равные опорному могут попасть в любую из них — тут вторая тройка ушла налево. Ровно так эти шесть чисел делит libstdc++: 3 3 1 | 7 7 9. Три группы (меньше / равно / больше) — отдельный приём для данных с кучей повторов.
• Миллион чисел — около 20 уровней деления: log₂ 1 048 576 = 20. На деле std::sort делает 22–25 сравнений на число, нижняя граница — ≈18,6.
• Маленькие куски досортировываются вставками. Если деление слишком глубокое (в libstdc++ предел 2·log₂N), introsort переходит на пирамидальную сортировку и в n² не скатывается.
• Если спросят „а в других языках?“ — Java для примитивов: dual-pivot quicksort, Python: TimSort, Go: pdqsort (с 1.19), Rust sort_unstable: ipnsort, наследник pdqsort.
• В замере: std::sort, потом std::unique сдвигает уникальные в начало, хвост удаляем erase.
