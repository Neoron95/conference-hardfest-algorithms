Маленький пример · одна вставка, одна коллизия, один повтор

ХЕШ ВЫБИРАЕТ МЕСТО, РАВЕНСТВО ПРОВЕРЯЕТ КЛЮЧ

Учебный хеш: h(x) = x mod 4

7 выбирает бакет 3

3 выбирает тот же бакет

Бакет 3

7

3

Вторая 7: ключ уже есть, вставка не нужна

Коллизия: один бакет. Повтор: равные полные ключи.

Таблица отвечает: встречалось ли такое число? Для примера хешом будет остаток от деления на четыре. Реальный хеш в замере другой.
[щелчок] Семь даёт три. В бакете номер три пусто, сохраняем семь.
[щелчок] Число три тоже выбирает этот бакет. Это коллизия, но три не равно семи. Сохраняем оба ключа. Один адрес ещё не означает одинаковые значения.
[щелчок] Приходит вторая семёрка. Находим полный ключ семь и ничего не добавляем. Вот это повтор.
Цена вставки — хеш, поиск, проверка равенства и иногда выделение памяти. И запомните: ячейка хранит не само число, а адрес, где число лежит. Через несколько минут этот адрес станет главным героем.
