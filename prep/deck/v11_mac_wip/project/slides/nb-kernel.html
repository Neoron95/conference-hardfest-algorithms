Под рукой:
• Apple формулирует влияние QoS на размещение: https://developer.apple.com/news/?id=vk3m204o (22.06.2020). Контроллер производительности задаёт рекомендации, исходники Edge допускают utility на всех CPU. Это описание модели планирования, не гарантия ядра для отдельного запуска.
• XNU xnu-12377.121.6, osfmk/kern/sched_clutch.c, стр. 6604–6612: https://github.com/apple-oss-distributions/xnu/blob/xnu-12377.121.6/osfmk/kern/sched_clutch.c#L6604-L6612 . Ограничение BG/Maintenance: performance controller would never recommend execution on the P-cores. На слайде пересказ, не универсальный закон будущих чипов и версий iOS.
• Цитата старого AMP «utility и bg только на E» относится к коду под !CONFIG_SCHED_EDGE. Не выдавать её за действующее правило текущего Edge. Нельзя подтвердить активный планировщик iPhone без сохранённого паспорта той версии iOS.
• iPhone 14 Pro, A16 Bionic. Версия iOS и мобильные сырые данные не сохранены в доступных материалах исходной серии; размеры кэшей iPhone не подставлять из модели. Время — медианы, числа перенесены из существующей колоды.
• Кривые отдельного memory probe дают косвенное свидетельство: utility на iPhone по изломам ближе к background. Сам дедуп не трассировали; размещение его потока не измерено. Линии Mac utility в материалах нет, поэтому «Mac utility — P» не является сохранённым результатом этого probe.
• Swift Task: priority не задаёт executor. Task наследует actor isolation; созданный из MainActor Task с синхронным C++ вызовом может остаться на MainActor. Ожидание через await task.value может повысить приоритет. Замер через Swift Task не выполнялся. Первоисточник: SE-0304, разделы Task priorities, Priority Escalation, Context inheritance: https://github.com/swiftlang/swift-evolution/blob/main/proposals/0304-structured-concurrency.md . Не рекомендовать Task.detached автоматически: сначала определить реальный executor.
• Приоритет потока, тип ядра и роль процесса — разные условия. Не переносить данные utility в BGAppRefreshTask автоматически. Thread affinity на Apple silicon не поддерживается: https://developer.apple.com/forums/thread/703361 .
Источники: prep/research/apple.md §1, §5; исходный cores; SE-0304.
