Меняем только последовательность тех же ключей.
[щелчок] Случайный порядок даёт знакомую картину: сортировка чуть впереди. Серии одинаковых значений почти ничего не меняют. Размер и число разных ключей прежние.
А теперь посмотрите ещё раз на старый код из дифа. Он делал sort + unique и сохранял результат — значит, наши локальные id всё это время лежали отсортированными. Мы этим просто не пользовались. Что будет на отсортированном входе? [пауза 2 с] [щелчок] Sort плюс unique обгоняет хеш в шесть раз.
[щелчок] Почему: стандартная сортировка замечает готовый порядок и почти ничего не делает. Двадцать шесть команд на элемент вместо двухсот двадцати, тактов — в пять раз меньше, ошибок предсказателя — тоже в пять раз меньше. Помните третьего подозреваемого? На готовом порядке предсказателю почти нечего выбрасывать.
[щелчок] На CI у libstdc++ такой проверки нет: сравнений столько же, но ошибок предсказателя в десять раз меньше — отсюда выигрыш там в четыре с половиной раза. «Вызвали sort» — тоже не полное описание опыта. Скоро используем готовый порядок в решении задачи. И последнее про данные — на каких данных мы вообще мерили.

Источники и условия
M2 Pro/libc++, P-ядро, N = 2^20, U = N/2 (bench/mac/results/m2/E4.csv): случайный 21,5 / 25,5; серии 21,7 / 23,0; отсортированный 3,6 / 23,0 (sort ×6,3; разброс sort 16 % — точка короткая). Прежние M2-числа V9 (серии 15,5, отсортированный 2,0 — ×8) этим харнессом не подтвердились: старый вход «серий» был устроен иначе.
Счётчики M2 (m2/counters_ui.csv, sort + unique, U = N/2): случайный — 219,4 команды, 76,5 такта, 2,0 ошибки на элемент; отсортированный — 26,4 / 13,6 / 0,39. Только сортировка: 211 → 18 команд, ошибок 1,6 → 0.
iPhone P — то же (3,7 / 22,3, ×6). iPhone E 2 ГГц: серии помогают хешу (uset 165 → 111, flat 71 → 60), сортировка на отсортированном — 6,8 против 114 (×17).
CI (libstdc++): сравнений 23,9 в обоих случаях, ошибок 9,2 → 0,92; Xeon E4: sorted 18,9 / 84,8 (×4,5). Механизм libc++ upstream: __insertion_sort_incomplete с лимитом 8 перемещений после разбиения без обмена (cpp.md §4.2); на Apple — та же картина по счётчикам. На iPhone std::sort берётся из системной libc++: алгоритм определяет версия iOS.
