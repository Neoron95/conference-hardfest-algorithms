Сортировка

O(n log n)

std::sort(v.begin(), v.end());
v.erase(std::unique(v.begin(), v.end()),
v.end());

Хеш-таблица

O(n) ожидаемо

std::unordered_set<uint64_t> s;
s.reserve(v.size());
for (auto x : v) s.insert(x);
v.assign(s.begin(), s.end());

log₂ 10⁶ ≈ 20 — кажется, выбор очевиден

2:00–2:45. Дедупликация — это те самые три строчки из ревью. Два классических способа. Первый — отсортировать: после сортировки одинаковые id стоят рядом, и один проход их схлопывает. Это O(n log n). Второй — хеш-таблица: складываем id в множество, оно само отбрасывает повторы, потом выгружаем обратно. Это в среднем O(n) — линейно. Логарифм миллиона — около двадцати. На бумаге второй способ делает в двадцать раз меньше шагов. Я тоже сначала выбрал бы хеш-таблицу и закрыл тикет. Давайте проверим интуицию — вашу и мою.
