Тип ключа, хешер и версия меняют работу контейнера

Вот несколько способов хранить одно множество. В измеренных libc++ и libstdc++ unordered_set использует отдельные узлы. В Java HashSet опирается на узлы HashMap, а Long добавляет боксинг числового ключа. Число новых объектов зависит от значения и оптимизаций, поэтому «два всегда» не обещаем.

Swift Set использует открытую адресацию. Go с версии один двадцать четыре и Rust используют Swiss tables. Python set тоже хранит записи в таблице, но int остаётся объектом. C# HashSet хранит цепочки индексами в массивах, без отдельного объекта узла на каждый числовой ключ.

Тип ключа и хешер меняют цену. Эти исходники дают кандидатов для проверки, а коэффициенты получаем на своём входе и в своей среде. Название Set начинает разговор об устройстве, но не заканчивает его.
