Чтобы погрузиться чуть подробнее, представим нашу упрощенную задачу.

На устройстве есть локальные id записей. Id — просто число, по которому мы узнаём запись. С сервера приходит дельта: новая порция таких чисел. Из-за повторных запросов или пересечения страниц один id может прийти несколько раз.

На входе есть повторы. На выходе каждое значение должно остаться один раз. По сути удаление повторов. Самих записей мы здесь касаться сегодня не будем, работаем только с числами.

Три условия нашей задачи.
[щелчок] Локальные id уникальны: внутри них повторов нет.
[щелчок] Ключ — шестидесятичетырёхбитное число.
[щелчок] Работа несрочная, в режиме utility. (Бэкграунда)
