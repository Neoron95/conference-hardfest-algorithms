# Колода C2 «Исходный код» — тёмный HardFest + фирменные акценты

Отдельная копия колоды V35 с фирменным стилем компании «Исходный код» (по брендбуку «Визуальная концепция Исходного кода»). Основная колода и ветка `claude/conference-talk-prep-fkipal` не меняются.

Артефакт: https://claude.ai/artifact/MkFKs9vcT4Qw9iHnAE3rCQ

## Что изменено относительно V35
- **Шрифт бренда IBM Plex Mono**: весь моноширинный текст (код, `unordered_set`, подписи) и верхние подписи-кикеры над заголовками (жирным).
- **Знак компании** (черта, точка, галочка) — маленький серый у номера страницы на каждом слайде.
- **Слайд 2**: под именем строка компании — синяя иконка, «Исходный код», «iOS-разработчик · codesrc.ru».
- **Финал (39)**: синий штамп «ПРОВЕРЕНО» с галочкой из знака, по щелчку.
- **«Спасибо» (40)**: только один QR — «Оцените доклад», крупно; QR с контактами убран (nagornov.tech — в подсказках, назвать устно).
- Обложка и мемы — как в V35 (фирменные плашки и карточки пробовали и откатили).
- Текст, речь, порядок щелчков, данные и цвета графиков (бирюзовый — sort, розовый — хеш) — как в V35.

## Файлы
- `project/` — колода как в артефакте (ссылки `/_blob/…` — ассеты этого артефакта).
- `c2.py` — преобразование V35 → C2: `python3 c2.py <копия project>` (на ссылках основной колоды).
- `blobmap_c2.txt` — соответствие id ассетов: основная колода → эта колода.
- `sheets/` — все 50 видимых слайдов (последнее состояние каждого).
