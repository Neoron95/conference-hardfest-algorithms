unique — один проход: берём число, если оно не равно соседу

Давайте для начала вспомним теорию. Первый способ — сортировка. Возьмём восемь чисел.

[щелчок] Внутри std::sort — быстрая сортировка, точнее её доработанная версия, introsort. Берём опорное число, например три: всё, что не больше трёх, — налево, остальное — направо.

[щелчок] Дальше то же самое внутри каждой половины.

[щелчок] И ещё раз — пока куски не станут по одному. 

На каждом уровне мы проходим по всем числам — отсюда n log n. Собирать обратно ничего не нужно: каждое число уже стоит на своём месте.

[щелчок] И смотрите: одинаковые встали рядом. Остаётся один проход слева направо: берём число, если оно не равно соседу.

Подсказки
• Пополам — идеальный случай: опорное попадает в середину. На случайных данных части неровные и уровней немного больше, но их число всё равно растёт как log n. Если деление слишком глубокое (в libstdc++ предел 2·log₂N), introsort переходит на пирамидальную сортировку и в n² не скатывается.
• Равные опорному могут попасть в любую из двух частей. Маленькие куски досортировываются вставками.
• Собирать половины (сливать) нужно в сортировке слиянием — так устроены std::stable_sort и TimSort в Python. std::sort делит на месте.
• log₂ 1 048 576 = 20. На деле std::sort делает 22–25 сравнений на число, нижняя граница — ≈18,6.
• Если спросят „а в других языках?“ — Java для примитивов: dual-pivot quicksort, Python: TimSort, Go: pdqsort (с 1.19), Rust sort_unstable: ipnsort, наследник pdqsort.
• В замере: std::sort, потом std::unique сдвигает уникальные в начало, хвост удаляем erase.
