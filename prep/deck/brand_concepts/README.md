# Фирменный стиль «Исходного кода» в докладе — концепты

Черновики, в колоду не внесены. Figma с визуальной концепцией из облачной сессии не открылась (сеть), поэтому концепты построены по иконке компании: синий #081DE6, белый знак из трёх элементов — черта, точка и галочка.

`slides/*.html` — слайды в формате колоды (можно вставить в артефакт как есть), `png/` — рендеры, `gen.py` — генератор (берёт слайды из `v11_mac_wip/project`).

## Задача 2: компания на слайде 2
- `about-co-a` — строка с иконкой: «Исходный код», под ней «iOS-разработчик · [сайт компании]».
- `about-co-b` — текст как был, внизу синяя плашка компании: иконка, название, «[сайт компании] · мы нанимаем».

## Концепт A — «подпись» (минимально, стиль HardFest не трогаем)
- `A-final-stamp` — штамп «Проверено на себе» в фирменном синем, галочка из знака компании.
- `A-share-mark` — маленький знак компании рядом с номером страницы на каждом слайде.
- Плюс вариант слайда 2 из задачи 2.

## Концепт B — «фирменный синий» (смелее)
- `B-final-blue` — финальная мысль на синем фоне, штамп белый.
- `B-divider` — пример разделителя части на синем (если захотим разбить доклад на части; добавляет слайды).

## Версия 2 — по брендбуку «Визуальная концепция Исходного кода»
Палитра: синий #001EF0, белый, светлые #FAFBFF / #F1F3FF / #E3E7FF, чёрный. Шрифт IBM Plex Mono (заголовки Bold прописными). Синие плашки с текстом поверх фото, знак в углу картинок, мем в светло-голубой карточке. Сайт — codesrc.ru (из брендбука).

`slides2/`, `png2/`, генератор `gen2.py`.

**C1 — фирменный светлый** (весь доклад в стиле компании): `C1-cover` — синяя обложка со знаком; `C1-share` — пример слайда с данными: белый фон, строки в светлых карточках, sort — синим, хеш — чёрным; `C1-meme` — мем в светло-голубой карточке.

**C2 — гибрид** (тёмный HardFest остаётся, фирменные акценты): `C2-about` — синие плашки «iOS-разработчик / Исходный код» на фото и знак в углу; `C2-meme` — мем в фирменной карточке; плюс синий штамп на финале (`slides/A-final-stamp`).

**Слайд 2 в текущем стиле**: `T2-about-row` — иконка, «Исходный код», «iOS-разработчик · codesrc.ru».
