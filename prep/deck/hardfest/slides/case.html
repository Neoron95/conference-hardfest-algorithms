На устройстве есть локальные id записей. Id — просто число, по которому мы узнаём запись. С сервера приходит дельта: новая порция таких чисел. Из-за повторных запросов или пересечения страниц один id может прийти несколько раз.

На входе есть повторы. На выходе каждое значение должно остаться один раз. Это удаление повторов, или дедупликация; дальше я иногда буду говорить коротко: дедуп. Самих записей мы здесь не касаемся, работаем только с числами.

Три свойства нашей задачи. [щелчок] Локальная часть уже отсортирована и уникальна. [щелчок] Ключ — шестидесятичетырёхбитное число. [щелчок] Работа несрочная, в режиме utility.

Каждая деталь ещё изменит решение. В тестовых сериях id случайные; для последовательных чисел ответ может отличаться. Сначала сравним два привычных способа убрать повторы.
