Backup · без шагов. Вопросы: «А в Java/Kotlin, Go, Rust, Python, Swift?» (qa B1–B3, B9, S1), «Почему не всё на Swift?» (X12).
Ответ: это карта устройства по исходникам, не замеры. Go с 1.24 и Rust — плоские Swiss tables, как Abseil. Swift и Python — тоже открытая адресация, но у Swift дорогой SipHash, а у Python каждый int — объект. C# — цепочки, но внутри массивов, без аллокации на элемент. А Java HashSet<Long> и котлиновский distinct() — узловые, да ещё с боксингом: два объекта на каждый id. Так что раунд 1 — про Java и Kotlin даже больше, чем про C++. Плоские замены на JVM — fastutil LongOpenHashSet и androidx MutableLongSet.
Процессор выбирает и здесь: Arrays.sort(long[]) на x86-Linux в новых JDK — SIMD-интринсика, на ARM — скалярный dual-pivot quicksort; Go выбирает хеш-функцию по CPU, пороги мерили на Zen 4 и Apple M1.
Swift (S1): Set плоский, но SipHash-1-3 дороже тождества; ожидаю ближе к flat, чем к unordered_set, где он относительно сортировки — не знаю, не мерил.
Почему доклад на C++ (X12): один и тот же код без изменений на x86, Mac и iPhone — иначе сравнение платформ смешалось бы со сравнением языков.

С экрана убрано: Устройство подробно: C++ std::unordered_set — узловая: узел на ключ, цепочки; Swift Set<UInt64> — плоская: открытая адресация, линейные пробы; Go ≥ 1.24 map[uint64]struct{} — плоская: Swiss table, группы по 8; Rust HashSet<u64> — плоская: hashbrown (Swiss), группа 16 на x86, 8 на ARM; Java / Kotlin HashSet<Long>, distinct() — узловая + боксинг: два объекта на id; Python set — плоская, но каждый int — объект в куче; C# HashSet<long> — цепочки в массивах: без new на элемент, без боксинга. Хешер для целого: C++ — тождество; Swift — SipHash-1-3, случайный сид; Go — скалярный, сид на каждую карту; Rust — SipHash-1-3, случайный сид; Java/Kotlin — (int)(v ^ v>>>32), без сида; Python — hash(int), без сида; C# — (int)v ^ (int)(v >> 32), без сида. sort + unique: C++ — sort + unique; Swift — sort() + проход; Go — slices.Sort + slices.Compact; Rust — sort_unstable() + dedup(); Java/Kotlin — Arrays.sort(long[]) + проход; Python — sorted() + проход; C# — Array.Sort + проход.
