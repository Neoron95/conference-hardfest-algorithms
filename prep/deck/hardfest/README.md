# Колода в стиле HardFest, версия 2

Исходники `../hardfest2026_deck.pptx`: те же 47 слайдов, что в `../project/`, но переписанные под шаблон организаторов
и под правило «меньше мелкого текста». Сборщик и шаблон — в `../pptx/`.

## Что изменилось по сравнению с первой версией

- На слайде остаётся тезис (заголовок в 1–2 строки), крупные числа и один визуал. Минимальный кегль на основных
  слайдах — 12 pt, подвалов нет.
- Всё, что убрано с экрана (условия замеров, источники, второстепенные числа), дописано в заметки спикера:
  абзацы «Условия и источники (были в подвале слайда)» и «С экрана убрано».
- Число шагов анимации на каждом слайде совпадает с числом `[щелчок]` в тексте выступления.
- Приёмы шаблона: крупные бирюзовые номера шагов, шевроны (карта раундов, слияние), цитата с бирюзовой скобкой,
  пункты «+ / −», карточки с белой рамкой и бирюзовая карточка-акцент, раздел backup с картинкой на пол-слайда.
- Анимации MP4 запускаются вместе со своим шагом (или со слайдом), крутятся по кругу без звука.

## Файлы

- `slides/<id>.html` — один слайд (холст 1920×1080, абсолютное позиционирование), `<aside>` — заметки.
- `hf.css` — дизайн-система: размеры шрифтов, цвета, карточки. Каркас: логотип x 1586–1816 / y 144–223,
  номер слайда x 1760–1868 / y 934–1017, контент x 117–1803 / y 300–960.
- `deck.json` — порядок и разделы.
- `assets/` — иллюстрации и анимации; исходники в `assets/src/img` и `assets/src/anim` (рисуются кодом, рендер — Chromium,
  видео — ffmpeg/libx264). `assets/PROMPTS.md` — промпты, если захочется сгенерировать картинки в нейросети.
- `tools/setslide.py` — заменить надзаголовок, заголовок и тело слайда, сохранив заметки (`--note` дописывает
  убранный с экрана текст в заметки).

## Сборка

```bash
node prep/deck/pptx/extract.js --deck hardfest          # раскладка + превью в /tmp/hardfest-pptx/extract-hardfest/orig
python3 prep/deck/pptx/build.py --deck hardfest         # -> prep/deck/hardfest2026_deck.pptx
```

Нужны шрифты Montserrat и JetBrains Mono (Google Fonts), Node.js с Playwright и Python с python-pptx, lxml, Pillow.
