# V30 (Mac) — снимок колоды для выступления

Снимок колоды «O(n) проиграл O(n log n)» (HardFest 2026, главная машина — M2 Pro) на версии артефакта 1791920957-d7a0 (с номерами страниц).

- `project/` — точная копия колоды из артефакта: `deck.json` и `slides/<id>.html`.
- `slides_text.md` — основная часть (39 слайдов): текст на слайде, речь и подсказки.
- `qa_slides_text.md` — оглавление и 9 слайдов-ответов на вопросы (позиции 40–49).
- `order_visible.txt` — порядок видимых слайдов (49).

PPTX этой версии лежат рядом, в `prep/deck/`:

| Файл | Что внутри |
|---|---|
| `hardfest2026_deck_v30_mac_clicks.pptx` | Для выступления. Слайды картинками, один в один с колодой; щелчки, видео, речь в заметках, ответы на вопросы после финала |
| `hardfest2026_deck_v30_mac_editable.pptx` | Текст и плашки редактируемые; щелчки, видео, заметки |
| `hardfest2026_deck_v30_mac_editable_prod.pptx` | Как editable, но только основная часть (39 слайдов) и без заметок |

Рабочая копия колоды и скрипты сборки — в `v11_mac_wip/` (`pptx_tools/build.sh`).
