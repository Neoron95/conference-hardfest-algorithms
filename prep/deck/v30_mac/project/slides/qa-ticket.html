Подсказки
• Условия: 512K id (2^19), половина разных, вся операция; нс на число, sort / хеш.
• Mac M2 Pro: 20,9 / 22,0 — разница 5 %, «ничья». CI Xeon: 84,2 / 75,0 — хеш ×1,12. iPhone 14 Pro в режиме utility: 46,6 / 105,8 — sort ×2,3.
• Для себя: тот же iPhone в userInitiated — 21,5 / 20,3, ничья. Дело в фоновом режиме, а не в «медленном телефоне». Здесь не раскрываем, только намёк «в фоне».
• Если спросят „CI на Linux, а прод на iOS — это же очевидно“ — да, но и Mac проблему не показал, хотя библиотека там та же, libc++.
• Id в замерах — случайные 64-битные: «как из синхронизации» — по размеру и доле повторов, не по значениям. На плотных id (автоинкремент) узловой таблице везёт: на CI она там в 1,7 раза быстрее сортировки (запасной слайд про плотные id).
