RADIX: УСТОЙЧИВЫЕ ПРОХОДЫ

Разряды вместо сравнений целых ключей

Посмотрим на числовой ключ. Вход: двадцать один, тринадцать, двенадцать, двадцать один, тридцать два, тринадцать. Можно не сравнивать каждую пару целиком, а обработать цифры по очереди. Это поразрядная сортировка, radix.

Начинаем с единиц, самого младшего разряда. Числа с единицей в конце кладём в одну группу, с двойкой — в следующую, с тройкой — ещё в одну. Собираем группы по порядку цифр. Оба числа двадцать один оказываются впереди, затем двенадцать и тридцать два, затем оба числа тринадцать.

Внутри группы сохраняем прежний порядок. Такое распределение называют стабильным: одинаковая текущая цифра не переставляет элементы между собой.

[пауза 2 с]
Теперь так же распределяем по десяткам. В группе с десятком один прежний порядок оставляет двенадцать перед тринадцатью. В группе с десятком два остаются числа двадцать один. Благодаря стабильности порядок, полученный по младшей цифре, сохраняется внутри новой группы. Все числа теперь отсортированы.

[щелчок] Мы упорядочили числа по разрядам, без сравнений целых ключей. Если теперь применить знакомый соседний unique, останутся двенадцать, тринадцать, двадцать один и тридцать два.

Здесь для наглядности две десятичные цифры. В бенчмарке ключ uint64_t состоит из восьми байтов. Реализация делает до восьми проходов по байтам: одинаковый у всех ключей байт можно пропустить. Число проходов для этого типа ограничено константой, поэтому работа растёт линейно с размером массива. Нужен дополнительный буфер, его выделение и освобождение тоже входят в замер.
