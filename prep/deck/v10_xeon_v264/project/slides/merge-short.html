Вспомним, что мы нашли: старый sort + unique каждый раз сохранял локальные id отсортированными. Локально у нас один, три, семь — по порядку, без повторов. Новая дельта — три, два, семь, два, девять.
[щелчок] Сортируем только дельту и убираем её повторы. Две отсортированные последовательности, каждая уникальна.
Держим по позиции в каждой. Меньшее число записываем и двигаем его позицию. При равенстве записываем один раз и двигаем обе.
[щелчок] Один, два, три, семь, девять. Позиции идут только вперёд, слияние линейно по общей длине. Локальную часть повторно не сортировали. Проверим рецепт на больших данных.
