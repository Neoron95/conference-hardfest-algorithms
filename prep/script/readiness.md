# Готовность V5

Основной показ — 33 слайда, ещё 24 скрыты для вопросов. Бюджет 32 минуты рассчитан под предполагаемый темп 140–150 слов/минуту; фактический темп пока не измерен. Речь — около 4,2 тысячи слов.

Добавлены учебные разборы sort + unique, узловой хеш-таблицы, Big-O, LSD radix и слияния. Четыре новые MP4 дополняют четыре прежние анимации. Учебные примеры не являются новыми бенчмарками.

Слайды и речь согласованы по щелчкам. В заметках сначала речь, затем источники; сокращения и полная справка находятся в сценарии. Данные измерений и границы выводов сохранены.

Перед выступлением: два прогона вслух, проверка понимания теории одним слушателем и проверка шрифтов, восьми видео, автозапуска и возврата из backup в PowerPoint на компьютере показа. В этой среде PowerPoint не установлен. PDF — статичная запасная версия с постерами, в нём все появления раскрыты.

Отдельные мемы пока не включены: они предложены для выбора. V4 доступна в теге v4, V5 сохраняется отдельным коммитом и тегом v5.
